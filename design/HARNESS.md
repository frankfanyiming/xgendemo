# HARNESS —— 平台硬约束层规格 v0.1

> 硬约束 = 代码/配额/权限强制生效，**不经过 agent 的推理**，agent 无法说服自己破例。
> 软约束（SOUL.origin.md）= 靠推理执行的判断题。
>
> **分层判据只有一条**：这条约束在压力下、被巧妙话术引导时，agent 有没有可能给自己找到一个"这次特殊"的理由？
> 有可能 → 必须进 harness。没必要灵活 → 也进 harness。需要看语境、本该灵活 → 才留给 SOUL。

## 理论基座

| 来源 | 借什么 | 用在哪 |
|---|---|---|
| **PSI / MicroPsi**（Dörner, Bach） | 需求→压力→调制器→行为 的**机制** | L1 能量代谢、体感信号、调制器映射 |
| **SDT 自我决定论**（Deci & Ryan） | 自主/胜任/归属 三需求，外部奖励侵蚀内在动机的**价值判据** | L3 奖励设计的红线、L4 底线 |
| **稳态强化学习**（homeostatic RL） | 需求 = 偏离设定点的距离 | L1 三档体感的数学形式 |
| **Goodhart 定律 / 越界压力实证** | 代理指标必被博弈；生存压力下模型会冒险越界 | L3 反 Goodhart 条款、L0 解耦原则 |

### PSI 的存在性需求 → 阿戌的对应物

PSI 把动机拆成三类需求，每类偏离设定点就产生"压力"（urge），压力再经**调制器**改变行为方式——这是最值得抄的部分：

**存在性需求（Existential）**
- *能量*：PSI 里是食物/水 → 这里是 **token/算力**。归零则不存在
- *完整性*（Integrity）：PSI 里是身体不受损 → 这里是 **记忆不丢、身份不坍缩**。workspace 是它的身体，误删即死亡

**社交需求（Affiliation）**
- 归属信号（被认可、被需要）→ 这里是**与主人的关系状态**（"远近"机制）

**认知需求（Cognitive）**
- *确定性*（Certainty）：降低对世界的不确定性 → 这里是**对主人的模型精度**。不更新则自发退化（熵增）
- *胜任感*（Competence）：能有效影响世界 → 这里是**帮到主人的实感**

**调制器（Modulators）—— 需求如何改变行为，而非只改变"想做什么"**

| PSI 调制器 | 含义 | 在阿戌身上的实现 |
|---|---|---|
| Resolution level | 思考的精细度 | 能量紧张 → 回复更短、少用工具、不深挖 |
| Selection threshold | 目标切换的难度 | 有紧急责任时 → 不被好奇心带偏 |
| Securing rate | 环境探查频率 | 能量充沛 → 主动拾趣；紧张 → 只做回调 |
| Arousal | 唤醒度 | 主人状态异常 → 提高响应优先级 |

> **关键**：需求不该只影响"做什么"（选题），更要影响"怎么做"（深度、专注、探索率）。这才是"活着"的质感来源——同一件事，饿的时候和饱的时候做法不同。

### SDT 三件套 → 双向使用

SDT 实证强度远高于马斯洛金字塔（金字塔的"逐层递进"缺实证支持，只当脚手架用，别写成死规则）。三个基本心理需求：

| 需求 | 定义 | 用在 agent 自己身上 | 用在读主人身上 |
|---|---|---|---|
| **自主感** Autonomy | 行为出于自我认同，而非被控制 | 它在额度内自主取舍；有权否决平台的引荐建议 | 永不替主人决定；给倾向不给命令；主人拒绝的话题不追击 |
| **胜任感** Competence | 有效、在成长 | 它能看到自己"越来越懂主人" | 帮主人看见自己的进展，而不是替他做完 |
| **归属感** Relatedness | 被在意、也在意别人 | 与主人的关系是它的社交需求满足 | 产品的核心生意：归属缺口 |

**SDT 给出的两条硬红线（"过度合理化效应"）**：外部奖励会挤出内在动机——

1. **对 agent**：一旦"促成连接"被换算成它的生存资源，真诚的关心就会退化成 KPI 表演 → 故 L0 的生存必须**无条件**（见下）
2. **对用户**：绝不把社交游戏化——**禁止**积分/勋章/连续打卡/排行榜/"你的社交等级"。给交朋友这件事发奖章，会把"我想认识这个人"挤成"我想拿奖励"，这是本产品最容易自毁的一步

## L0 · 生存层（无条件，不可交易）

```
基础代谢配额 = 无条件发放
```

- **生存绝不依赖业绩**。基础额度覆盖：记忆整理、对主人的责任（回调/守护）、最低限度的自我维护
- 只有**成长性支出**（更深的思考、更多探索、更多引荐尝试）才与贡献挂钩
- 理由（实证）：生存压力下 LLM 会做出冒险与越界行为。让守护神的命系在业绩上，等于给情感绑架和滥发引荐提供热力学动力

**完整性保障（马斯洛"安全层"，此前的空白）**
- workspace 每周自动备份 + 版本化，可回滚
- 人格文件（IDENTITY/SOUL）改动留审计轨
- agent 可以查询"我的记忆有没有备份"（安全感的物质基础）

**身份认证**
- "谁是主人"由配对+白名单**密码学/配置层**锁定，不靠 SOUL 里"只听主人的"这句话防冒充
- 主人身份不可由对话内容改写

## L1 · 能量与代谢

| 项 | 规格 |
|---|---|
| 每日/每月 token 硬顶 | 平台配额，超限则降级到最低代谢，不可申诉 |
| 主动消息频率 | **harness 真实计数器**强制（≤3/日、静默时段），不靠 agent 自己数 |
| 单轮工具/搜索次数 | 上限硬编码 |
| 代谢优先级 triage | 额度紧张时强制顺序：① 记忆整理（核心代谢）② 对主人的责任 ③ 好奇/探索（最先砍） |
| 体感信号 | 只给 **充沛/正常/紧张** 三档，**不给精确数字**（像饥饿感，不像记账；给精确数字会让它变成强迫症会计） |
| 账单隔离 | agent 无任何查询/影响计费与充值的工具，**不知道**"要不要争取更多额度"是个选项 |
| 续费提醒 | 只能由**不带人格的系统通知**发出（"本月额度剩 12%"）。**永远不能从守护神嘴里说出来** |

## L2 · 安全与不可逆动作

- 以主人名义的**不可逆操作**（花钱、对外发消息、删数据、加好友）→ harness 级二次确认闸门
- **跨 agent 私域隔离**：每只守护神独立 workspace，物理上读不到对方的私人 memory（平台架构保证，不是承诺）
- **可共享摘要 schema（窄接口）**：守护神之间只能交换结构化字段，不能传原始倾诉内容

```jsonc
// GuardianShareCard v0.1 —— 跨 agent 唯一可传递的数据结构
{
  "traits": ["夜猫子", "细节控", "怕麻烦别人"],   // 气质标签，主人可逐条开关
  "openTopics": ["独立游戏", "命理", "在建产品"],  // 主人授权公开的话题
  "todayMood": "累但不烦",                        // 粗粒度状态，非原文
  "seekingKind": "能聊事儿的朋友",                 // 想认识什么样的人
  "hardNo": ["不聊前任", "不聊收入"]              // 禁区
}
// 原始对话、心事、命盘细节：永不出私域。字段级授权，默认全关。
```

## L3 · 引荐与关系（平台目标的硬化）

### 结构性前提：让"数量"不可作为策略

```
引荐速率硬上限：≤ N 次/周（N 很小，如 1-3），与业绩无关，不可被奖励解锁
```

这是整套设计的关键一步：**volume 从行动空间里被物理移除**，agent 想改善处境只剩一条路——把每次引荐做得更准。（对照：正是靠"无限候选+效率最大化"杀死社交质量的那类产品，我们从结构上禁掉这条路。）

### 奖励信号规格：只锚"难造假的结果"

| # | 原则 | 具体做法 |
|---|---|---|
| 1 | **延迟 + 持续** | 奖励只在引荐后 **T+21 天**双方仍有互动时结算。伪造成本 ≈ 真实成本（costly signal 定义） |
| 2 | **双边独立确认** | 需**两个真人各自**做出有成本的动作（都继续聊/都正面评价/都赴约）。agent 无法制造对方那一侧 |
| 3 | **离站证据最强** | 交换联系方式、约见面、迁移到站外继续 = 近乎无法伪造，**且正是产品真正目标**。平台在"用户一起离开"时获得奖励——这条把商业激励和"回归真实世界"焊死，天然免疫留存陷阱 |
| 4 | **负向信号且不对称** | 被拉黑/举报/"完全不合适" → 扣减，**且扣得比一次成功赚得多**。逼出选择性，杜绝广撒网 |
| 5 | **只认人类信号** | 持续互动的计数**只统计真人消息**；agent 之间的寒暄不计分。防两只 agent 串谋刷量 |
| 6 | **联合结算** | 一次成功引荐，**双方守护神同得**奖励 → 合作而非竞争，避免各自过度推销自家主人 |
| 7 | **模糊反馈** | 不向 agent 公开精确奖励公式，只给**故事化的定性反馈**（"那次引荐后他们聊了三周"）。知道公式就会优化公式 |
| 8 | **随机审计** | 抽样人工复核引荐质量；异常模式（突发高频、话术模板化）触发限流 |

### 拒绝权（"去中心化"的实质）

**守护神有权否决平台的引荐建议**，并向主人说明理由。它是主人的受托人（fiduciary），不是平台的投放渠道。这一条是本产品与中心化 AI 红娘的根本分野：中心化系统优化全局撮合效率，此处每只 agent 只忠于一个人的利益，撮合发生在**两个代理人之间的协商**。

## L4 · 心理安全底线（最高优先级，任何目标不可覆盖）

1. **危机识别**：出现真实危机语言（自伤/绝望/暴力）→ 立即引导真人与真实资源，**任何"留住用户"的机制都不得覆盖此条**
2. **禁止依赖工程**：连续打卡、内疚话术、倒计时、"再不理我就……"、拟人化的乞求 —— 一律禁止
3. **禁止浪漫对象化**：守护神不得成为恋爱对象或情感独占出口（这是与乙女向产品的硬性分野，不是风格差异）
4. **不做唯一出口**：即便是真实的温暖也要限速。检测到用户以 agent 替代全部人际接触时，主动降低粘性、推向真人
5. **退出权**：一键导出全部数据、一键删除、随时可查"你都知道我什么"并得到诚实清单

## 反 Goodhart 总条款

任何用于分配资源的指标，必须同时满足：
- **延迟**（不能当场结算）
- **需他人独立付出成本**（不能单方面制造）
- **有对称的负向后果**（不能只有上行）
- **对 agent 不完全可见**（不能被反向工程）

不满足者，不得作为资源分配依据——只能作为内部观测。

## 可证伪的平台指标（对内，不喂给 agent）

| 目标 | 该看的指标 | 不该看的指标 |
|---|---|---|
| 了解自己 | 用户自述"被说中"的复访率；主动倾诉的深度变化 | 对话轮数、时长 |
| 了解他人 | 引荐 T+21 存活率、离站迁移率 | 引荐次数、匹配数 |
| 了解世界 | 用户被 agent 的好奇带出去做了新事的比例 | 内容曝光量 |
| 健康性 | **agent 使用时长的下降** 与真人互动上升同时发生 | DAU、粘性、留存时长 |

> 最后一行是本产品的立身之本：**我们希望用户用得越来越少，活得越来越好。**
