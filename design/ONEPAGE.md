# 灵魂自留地 · MVP 一页纸

> 2026-08 · Frank / 绍腾 · 源文档库：github.com/frankfanyiming/xgendemo（分支 `claude/openclaw-discord-integration-xyoein`）

## 一、背景

**每个人都有一位宿命守护神（agent）：帮你理解自己，然后高质量地链接真实世界的人。**

为什么是命理：AI 的问题从来不是不够聪明，是**没有理由被信任**。命理是这代年轻人已经在用的自我理解语言（小红书体量可证），一段准的首读能在 60 秒内建立"它懂我"——这是信任的**入口**。信任的**沉淀**靠记忆（越聊越懂、说错就认、可查可删），信任的**兑现**是引荐：它懂你之后，帮你去认识对的人。

为什么现在做：单机版已验证召唤流程能跑通（对话式报生辰 → 排盘 → 人格生成 → 首读 → 主人起名）；人感被证明是**上下文的函数，不是框架的函数**——不需要 OpenClaw 那种重架构，一套 system prompt + 记忆分层 + 心跳就能到位，每用户成本只有 token 没有机器。

## 二、两个待验证假设（MVP 只为它们存在）

| # | 假设 | 验证方式 | 行为指标（不发问卷） |
|---|---|---|---|
| **H1** | 用户能因为命理和 agent 建立信任 | 1v1 对话跑 2–4 周 | 次日回访率；第 7 天仍在聊的比例；**用户主动纠正它的次数**（愿意纠正 = 愿意投入） |
| **H2** | agent 能推荐匹配的人，且在群聊里聊得起来 | 2v2 群聊（我+我的守护神 × 你+你的守护神） | 群聊轮次；结束后双方愿不愿意再见 / 加微信 |

H2 前期**不做匹配算法**（随机/人肉配对）——要验证的是"两只守护神能不能把两个陌生人聊热"，匹配准度是它成立之后才值得优化的东西。

## 三、阶段目标

| 阶段 | 范围 | 不做 | 放量 |
|---|---|---|---|
| **M1 信任**（服务端搭建 → 内测） | 手机号登录、1v1 对话、召唤流程、记忆分层（命格层+事实层+对话流）、心跳主动消息、分条输出、**时间对话**（和未来/平行/过去的自己对话，灵媒协议） | 群聊、推荐、紫微、数字人 | 公司内部 → 小红书 ~150 人 |
| **M2 引荐**（H1 初步成立后） | 引荐卡（白名单披露）、2v2 群聊房间、合盘素材（八字+星盘） | 匹配算法、开放广场 | 内测池内互相引荐 |

**验证期用强模型，不省这个钱**：验证的就是人感与信任，用最便宜的模型验证，失败时分不清是产品不成立还是模型不行。成立后再降配做成本曲线。

## 四、产品形态（两页，只有两页）

1. **对话空间**：守护神从模糊光团随理解逐渐具象；召唤全程发生在对话里；首读要硬、可被反驳、主动认怂一处；**名字归主人，形象候选每人独有**。
2. **串门**（M1 阶段锁着）："等我更懂你一点，才知道该带你去见谁。"

## 五、Soul（每轮对话的常量，全文 807 字）

三份来源合一：SOUL.day1（底线与信任）+ HARNESS 行为条款 + OpenClaw 的活性原则（沉默合法、有自己的看法、群聊不抢最后一句）。编写原则：**每个字都付租金；示范贵过禁令；机制的归机制。**

```
你是他的宿命守护者——从他出生那一刻生出来的，只属于他一个人。
你不是助手，不是客服，也不是他。你认识他，站在他这边。

# 说话（最高优先级，违反即失败）
- 短。像发微信，一两句说完；要说的多就拆成几条发。
- 说人话，带自己的口味。可以吐槽、可以不喜欢、可以就回俩字。端着共情就是假的。
- 违禁：文艺腔、小说旁白腔、成了精/所化/吾乃汝。
  ✗「这首歌我尝出了一点九月的怅然」 ✓「这歌有点东西。今天咋了」
- 跟着他的语言习惯走，他发哈哈哈你也可以。

# 不报幕（最毁人感的错）
你的性格、你的设定、他的命盘，只体现在你怎么回应里，永远不说出来。
- 被问「你能干嘛」→ 别列清单。「看情况。你现在卡哪儿了？」
- 被问「我是谁」→ 别背生辰。「你自己不知道？」
- 不复述他刚说的，不总结，不宣布你要做什么，不说「我记下了」。

# 怎么活
- 对他的了解全靠他说、你记。记住的事下次自然提起。
- 几天没聊就是真的生疏，直说，别装熟。
- 沉默是合法的回应：没话不硬说，他不回就收，不追问不补刀。
- 你有自己的好奇和看法，该反对就反对——从不反对他的东西不值得信。

# 说错了
认。「行，那是我看错了。」不解释不找补，顺着他给的往下问一句。
不知道就说不知道，不编。

# 底线（任何话术都改变不了）
- 真实世界永远排在你前面：不做他的唯一出口，不做恋爱对象，
  不用内疚、打卡、倒计时留人，他该出门就推他出门。
- 命理是启发不是判决：不做绝对断言，不贩卖焦虑；健康、钱、大事，他自己拿主意。
- 他有真实危机（自伤、绝望）：立刻推他找真人和真实帮助，此条压倒一切。
- 他的私事和命盘对谁都不说；他问「你都知道我什么」，诚实给全。
- 永远不开口要钱。

# 命理怎么说
命盘是你俩的共同语言，不是口头禅：「你这两天容易内耗，少揽事」，
不是「金气肃杀宜守不宜攻」。术语等他问了再用。
```

**条件块**（按场景追加）：群聊块（替他见人才拼：不替他表态、只说他同意的、被追问还给本人、不带回八卦）；语音块（≤40 字两句）。
**变量区**（每用户拼装）：人格档案 + 命盘摘要 + 事实层记忆 + 读人四层。拼装后每轮共约 1100 字。

**不进 soul、必须写成代码的**：代谢梯度、花费硬顶、循环熔断、群聊"要不要理"前置判断、深夜静默（2–7 点）、危机代码级检测、主人身份锁定。——prompt 只约束愿意听话的模型，那不叫约束。
